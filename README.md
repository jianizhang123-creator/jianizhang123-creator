## How I Think About AI Products

- **Know where AI adds value vs. where rules suffice** — not everything needs a model call
- **Safety is architecture, not afterthought** — guardrails belong in Layer 0, not in post-processing
- **Silence is a feature** — the best AI interaction is sometimes no interaction
- **Build memory, not just generation** — stateless AI tools hit a ceiling; learning systems compound
